RESPONSIVE

One app, four layouts

Web pages use container queries, so each one reflows when resized. Resize any web artboard to see the sidebar collapse and the rail drop.

  • Modals
    Desktop: centred dialog (copy flow, confirmations). Mobile: bottom sheet.
  • Notifications
    Desktop: top-right card + bottom-right toasts. Mobile: top banner + top toasts.
  • Tables
    Positions, Leaderboard and Guard become tables on web, cards on mobile.
  • Ask Cat
    Web: chat history column + centred thread, ⌘K from anywhere. Mobile: full-screen chat.
  • Keyboard
    / search · ⌘K Cat · A approve request · Esc closes dialogs.
  • Same state
    One account: chats, requests and Guard alerts sync across web, app and Telegram.
